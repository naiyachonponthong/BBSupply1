# BBSupply — หน้าเว็บระบบพัสดุ (GitHub Pages)

## ติดตั้งครั้งแรก

### 1. ฝั่ง Apps Script
1. เปิด Google Sheet ที่ใช้เก็บข้อมูล → ส่วนขยาย → Apps Script
2. สร้าง/วางไฟล์ให้ตรงชื่อ: `Code.gs` และ `API_LAYER.gs` (จากโฟลเดอร์ `gas/`)
3. ถ้าเคยติดตั้งเวอร์ชันเดิมไว้ ให้ **ลบไฟล์ HTML ทั้งหมดทิ้ง** (`index.html`, `css_*`, `js_*`) ไม่ใช้แล้ว
4. เปิด `appsscript.json` แล้ววางเนื้อหาจากไฟล์ในโฟลเดอร์เดียวกัน
5. เลือกฟังก์ชัน `setupApi` แล้วกดเรียกใช้ → อนุญาตสิทธิ์ → ดูผลลัพธ์ในบันทึกการทำงาน จะได้ URL และรหัสผ่านแอดมินครั้งแรก (ถ้ายังไม่มีผู้ใช้ในระบบ)
6. ทำให้ใช้งาน → เว็บแอป → ดำเนินการในชื่อ **ฉัน** · ผู้ที่มีสิทธิ์เข้าถึง **ทุกคน** → คัดลอก URL ที่ลงท้าย `/exec`

### 2. ฝั่งหน้าเว็บ
1. แก้ `web/js/config.js` ใส่ URL ที่ได้ในช่อง `API_URL`
2. อัปไฟล์ในโฟลเดอร์ `web/` ทั้งหมดขึ้น GitHub repository (ให้ `index.html` อยู่ระดับบนสุดของ repo)
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
4. รอ 1-2 นาที เปิดลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

> ทุกครั้งที่แก้ไฟล์ในโฟลเดอร์ `web/` แค่ push ขึ้น GitHub ก็เห็นผลทันที ไม่ต้อง Deploy Apps Script ใหม่
> จะต้อง Deploy ใหม่เฉพาะตอนแก้ `Code.gs` หรือ `API_LAYER.gs` เท่านั้น

## โครงไฟล์

```
web/
├── index.html          โครงหน้าจอ + จุดโหลดสคริปต์
├── 404.html            พากลับหน้าหลัก (กัน GitHub Pages ขึ้น 404 ตอนรีเฟรช)
├── assets/theme.css    สีและเลย์เอาต์ทั้งระบบ (SECTION 1 = สี แก้ที่เดียว)
└── js/
    ├── config.js       URL ของ API + ชื่อระบบ
    ├── api.js          สะพานคุย Apps Script (ห้ามแก้รูปแบบคำขอ)
    ├── ui.js           toast, popup, ตาราง, ฟอร์ม, dropdown ค้นหาได้, แบบพิมพ์
    ├── auth.js         เข้าสู่ระบบ / session
    ├── app.js          โครงแอป เมนู และตัวจัดเส้นทาง
    └── pages/          หนึ่งไฟล์ต่อหนึ่งหน้า
        ├── dashboard.js
        ├── master.js    พัสดุ / บริษัทผู้ขาย / ผู้เบิก
        ├── stock.js     ใบสั่งซื้อ / รับเข้า / ล็อต
        ├── issue.js     เบิกจ่าย / ตรวจนับ
        ├── scan.js      เบิกด้วยการสแกน QR
        ├── reports.js   รายงานทั้งหมด
        └── settings.js  ตั้งค่า 6 แท็บ
```

ไฟล์ PWA: `manifest.json`, `sw.js`, `assets/icon-192.svg`, `assets/icon-512.svg`
service worker แคชเฉพาะไฟล์หน้าเว็บ **ไม่แคชคำขอที่คุยกับ Apps Script** ข้อมูลสต๊อกจึงสดเสมอ

## เพิ่มหน้าใหม่

```js
BBS.pages.mypage = {
  render: function (host) {
    return BBS.api('some.route').then(function (d) {
      host.innerHTML = BBS.head('ชื่อหน้า', 'คำอธิบาย') + '...';
    });
  }
};
```
แล้วเพิ่มไฟล์ใน `index.html` กับเพิ่มรายการใน `BBS.app.navItems` — เมนูจะขึ้นให้เองเมื่อหน้านั้นถูกลงทะเบียนและผู้ใช้มีสิทธิ์

## แก้ปัญหา

| อาการ | สาเหตุ |
|---|---|
| ขึ้น "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้" | `API_URL` ผิด หรือ Deploy ไม่ได้ตั้งเป็น "ทุกคน" |
| ขึ้น "ข้อมูลที่ได้กลับมาไม่ถูกต้อง" | Apps Script ตอบเป็นหน้า HTML แปลว่ายังไม่ได้ Deploy เวอร์ชันใหม่หลังแก้โค้ด |
| ล็อกอินไม่ได้ ไม่มีผู้ใช้ | รัน `setupApi()` ใน Apps Script หนึ่งครั้ง จะได้บัญชี admin พร้อมรหัสผ่านสุ่ม |
| แก้โค้ดหน้าเว็บแล้วไม่เปลี่ยน | กด Ctrl+F5 ล้างแคชเบราว์เซอร์ |
